# Check Project Specifications

## Instructions

1. Read through `specs/main.md`.
2. Repeat back to the user (in text) the tech stack and key specs to confirm understanding.
3. If the agent identifies missing pieces in the specs, ask the user.
4. If any specs are unclear or seem unnecessary, ask the user for clarification.
