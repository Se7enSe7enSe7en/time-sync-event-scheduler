### Start the local supabase DB

```sh
supabase start
```

#### note: depending on how you installed the supabase cli or not you may need to use `npx` before the cli command, eg. when you didn't install supabase cli and just use npx:

```sh
npx supabase start
```

- also you need to make sure docker is running before you start the supabase DB

### Stop the local supabase DB

```sh
supabase stop
```

### Check status

```sh
supabase status
```
